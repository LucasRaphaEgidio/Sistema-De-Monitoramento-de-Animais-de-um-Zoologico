# Sistema de Monitoramento de Animais em um Zoológico🐾

Projeto desenvolvido para a disciplina Certificadora de Competência 3 da UTFPR - Campus Cornélio Procópio.

## Sobre o Projeto
Aplicação desktop em Java voltada para o cadastro e gerenciamento de animais e espécies em um zoológico, incluindo o controle do histórico de alimentação e organização das informações em banco de dados.
